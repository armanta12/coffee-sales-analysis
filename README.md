# ☕ Coffee Sales Dashboard Analysis

Proyek ini merupakan implementasi **Dashboard Analisis Penjualan Kopi** menggunakan **Microsoft Excel**. Dashboard dikembangkan untuk membantu menganalisis performa penjualan berdasarkan waktu, negara, pelanggan, jenis kopi, ukuran produk, dan status loyalty card melalui visualisasi yang interaktif.

Seluruh proses dilakukan menggunakan fitur bawaan Microsoft Excel seperti **Pivot Table**, **Pivot Chart**, **Timeline**, dan **Slicer**, sehingga menghasilkan dashboard yang informatif dan mudah digunakan untuk mendukung pengambilan keputusan bisnis.

# 🎯 Tujuan Proyek

Proyek ini bertujuan untuk:

- Melakukan analisis terhadap data penjualan kopi.
- Menampilkan tren penjualan berdasarkan periode waktu.
- Mengidentifikasi negara dengan total penjualan tertinggi.
- Mengetahui pelanggan dengan nilai pembelian terbesar.
- Membandingkan performa setiap jenis kopi.
- Menyediakan dashboard interaktif yang mudah digunakan.
- Mendukung pengambilan keputusan berbasis data.

---

# 📂 Dataset

Dataset yang digunakan merupakan data transaksi penjualan kopi yang terdiri dari beberapa informasi, antara lain:

- Order Date
- Customer Name
- Coffee Type
- Roast Type
- Product Size
- Quantity
- Unit Price
- Sales
- Country
- Loyalty Card

Dataset dibagi menjadi dua bagian:

- **Raw Dataset** → Data asli sebelum diproses.
- **Processed Dataset** → Data yang telah disiapkan untuk pembuatan dashboard.

# 📊 Dashboard Overview

Dashboard menyajikan berbagai visualisasi utama untuk membantu pengguna memahami performa penjualan secara cepat.

Visualisasi yang tersedia meliputi:

- 🎛️ Filter Roast Type
